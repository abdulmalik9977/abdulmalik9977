# Hi, I'm Abdulmalik Hardan 👋

**Data Analyst** focused on supply chain and inventory analytics. I use SQL and Power BI to find where companies lose money to expiry and waste.

## 📊 Featured Projects

**[Pharma360](https://github.com/abdulmalik9977/Pharma360-Analytics)** – Sales performance & expiry risk analytics for pharmaceutical distribution

- Identified $2M in expired inventory cost (32% waste) across 6 Iraqi markets
- Built a 4-page executive Power BI dashboard
- Tools: MySQL, Power BI, DAX

**[Supply Chain Expiry Risk Analysis](https://github.com/abdulmalik9977/Supply-Chain-Expiry-Risk-Analysis)** – Inventory waste and root cause analysis

- Audited 880,044 expired units; pinpointed Baghdad warehouses as the main risk hub
- Proposed a FEFO workflow to reduce future losses
- Tools: MySQL, Power BI

**[Ride-Hailing BI Dashboard](https://github.com/abdulmalik9977/Ride-Hailing-Operations-Business-Intelligence-)** – Operations analytics for the Iraqi transport market

- Designed a MySQL database for 15,000 trips and 5,000 customers
- Built a dashboard tracking peak hours and customer churn
- Tools: Python, MySQL, Power BI, DAX
